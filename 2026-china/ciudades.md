## Geografía forzada por los vuelos

```
Entrada HKG ──► … ciudades … ──► Salida PVG
```

Dos lógicas sensatas:

1. **Norte primero** — HKG→Pekín en avión el día 12, luego oeste/sur hasta Shanghái (ruta “clásica”).
2. **Sur primero** — aprovechar HKG hacia Guilin/Hunan, subir a Sichuan/Shaanxi/Pekín y bajar a Shanghái (más tren, menos “saltar” al norte el primer día).

Con las mismas ciudades, **norte primero** suele dejar mejor Shanghái al final y permite Chongqing en sábado 24. **Sur primero** aprovecha mejor HKG pero aprieta Pekín/Xi'an al final.

## Escenario C — Sur primero (aprovechar HKG)

Orden:

```
HKG → Guilin/Yangshuo → Fenghuang → (Furong) → Zhangjiajie → Chongqing → Chengdu → Xi'an → Pekín → Shanghái
```

| Fecha | Plan (borrador) |
|-------|-----------------|
| 11 | HKG noche |
| 12–14 | HKG→Guilin + **Guilin/Yangshuo** (≈2) |
| 15–16 | Fenghuang (+ Furong si cabe) |
| 17–19 | Zhangjiajie (2) + margen traslado |
| 20–24 | Chongqing (**24 sábado drones**) — sobran días aquí o se adelanta Chengdu |
| 25–26 | Chengdu |
| 27–28 | Xi'an |
| 29–30 | Pekín (solo 2) |
| 31 | → Shanghái mañana + vuelo — **casi imposible** sin saltar Pekín o Shanghái |

**Pros:** geografía limpia desde HKG; menos vuelo el día 12.  
**Contras:** Pekín y Shanghái quedan ahogados; peor cierre con el vuelo PVG. **Solo tiene sentido si recortas Pekín a 2 y aceptas Shanghái = solo mañana del 31**, o si quitas Pekín del viaje (no recomendable: está confirmado).
